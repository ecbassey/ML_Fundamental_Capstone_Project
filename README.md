# ML_Fundamental_Capstone_Project
Customer Churn Prediction


### Problem Statement
Many organizations collect large amounts of customer data but fail to utilize it effectively for retention planning. This project aims to transform customer data into predictive insights by developing a churn prediction model capable of supporting data-driven business decisions.

### Skills & Tools:
- Python
- Data Cleaning
- EDA
- Statistics
- Classification Algorithms
- Machine Learning Fundamentals

### Insights and Solutions:
This project aims to uncover:
- Which Customers Are Most Likely to Churn
- The Main Factors Driving Churn
- Customer Behavior Patterns
- High-Risk Customer Segments
- The Most Effective Prediction Mode
