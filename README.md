# ML_Fundamental_Capstone_Project

Credit card fraud detection

### Problem Statement
Detecting fraudulent financial transactions presents a challenging classification problem due to the imbalance between legitimate and fraudulent activities. This project aims to build and evaluate machine learning models capable of accurately identifying fraudulent transactions while optimizing recall, precision, and overall detection performance.

### Insights and Solutions:
This project aims to uncover:
- Which transactions are likely fraud
- What patterns separate fraud from legitimate activity
- How can fraud be detected early
